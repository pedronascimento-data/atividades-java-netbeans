ATIVIDADE 1 - AGÊNCIA DE VIAGENS

Projeto Java console com orientação a objetos.

Classes:
- Transporte: tipo e valor.
- Hospedagem: descrição e valor da diária.
- PacoteViagem: transporte, hospedagem, destino, quantidade de dias e cálculos do pacote.
- Venda: cliente, forma de pagamento, data, pacote e conversão de moeda.
- Main: interação com o usuário via Scanner.

Cálculo do pacote:
1. Total hospedagem = quantidade de dias x valor da diária.
2. Subtotal = transporte + hospedagem.
3. Lucro = subtotal x margem / 100.
4. Total do pacote = subtotal + lucro + taxas adicionais.

Conversão:
- Dólar para real = valor em dólar x cotação do dólar.
- Real para dólar = valor em real / cotação do dólar.

Para abrir no NetBeans:
1. Descompacte o arquivo ZIP.
2. No NetBeans, use File > Open Project.
3. Selecione a pasta AgenciaViagens.
4. Execute a classe agenciaviagens.Main.
