# Atividades Java — NetBeans

Repositório com três atividades práticas em Java desenvolvidas no NetBeans.

## Estrutura

- `atividade-1-agencia-viagens/` — orientação a objetos, composição, cálculos de pacote e conversão de moeda.
- `atividade-2-folha-pagamento-rh/` — herança, classe abstrata, polimorfismo e repetição.
- `atividade-3-modulo-contabil-impostos/` — interfaces, polimorfismo e estruturas de dados com `List`/`ArrayList`.

Cada pasta contém um projeto NetBeans independente, com código-fonte e arquivos de configuração do projeto.
