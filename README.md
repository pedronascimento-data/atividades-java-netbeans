# Java POO — Atividades Práticas no NetBeans

Repositório com três projetos acadêmicos desenvolvidos em Java para praticar **orientação a objetos** aplicada a problemas de negócio.

Mais do que reunir exercícios, este repositório registra a evolução em conceitos fundamentais para desenvolvimento Java.

## Projetos

| Projeto | Cenário | Conceitos praticados |
|---|---|---|
| [Atividade 1 — Agência de Viagens](atividade-1-agencia-viagens/) | Montagem e venda de pacotes de viagem | classes, objetos, composição, encapsulamento e cálculos |
| [Atividade 2 — Folha de Pagamento](atividade-2-folha-pagamento-rh/) | Processamento de funcionários assalariados e horistas | classe abstrata, herança, sobrescrita e polimorfismo |
| [Atividade 3 — Módulo Contábil](atividade-3-modulo-contabil-impostos/) | Cálculo de PIS e IPI | interfaces, polimorfismo, listas e organização de regras de cálculo |

## Stack

- Java
- Programação Orientada a Objetos
- NetBeans
- Git e GitHub

## Competências demonstradas

- Modelagem de classes a partir de requisitos
- Separação de responsabilidades
- Reutilização por herança e interfaces
- Uso de polimorfismo
- Manipulação de coleções
- Implementação de regras de negócio e cálculos

## Como executar

Cada pasta é um projeto NetBeans independente.

1. Clone este repositório.
2. Abra o NetBeans.
3. Selecione **File > Open Project**.
4. Escolha a pasta da atividade desejada.
5. Compile e execute a classe principal do projeto.
