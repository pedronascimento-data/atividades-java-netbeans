ATIVIDADE 2 - SISTEMA DE RH / FOLHA DE PAGAMENTO

Projeto Java console para NetBeans.

CLASSES
- Funcionario: classe abstrata com os dados comuns encapsulados, mostrarDados(),
  calcularPagamento() abstrato e aplicarAumento() abstrato.
- Assalariado: herda Funcionario. Pagamento = salario mensal.
- Horista: herda Funcionario. Pagamento = horas trabalhadas x valor da hora.
- Main: cadastro, listagem, aumento geral e demonstracao de polimorfismo.

REQUISITOS ATENDIDOS
- Cadastro de 1 a 10 funcionarios.
- Escolha entre assalariado e horista.
- Uma unica lista do tipo Funcionario[] para os dois tipos.
- Encapsulamento com atributos private e getters/setters.
- Heranca com extends.
- Classe e metodos abstratos.
- Sobrescrita com @Override.
- Polimorfismo no vetor Funcionario[] e nas chamadas dos metodos.
- Estruturas de repeticao (for, do/while e while).
- Aumento geral informado em percentual.
- Exibicao dos dados e pagamentos antes e depois do aumento.

COMO ABRIR
1. Descompacte o arquivo ZIP.
2. No NetBeans, use File > Open Project.
3. Selecione a pasta FolhaPagamentoRH.
4. Execute o projeto (Run Project).
